# spa-react-python

A template repository from which React single-page apps backed by a Python API are created, so that each new one starts without novel boilerplate.

## Language

**Template**:
This repository: the source from which Projects are created.
_Avoid_: Boilerplate, starter, scaffold

**Project**:
A repository created from the Template, which then evolves independently of it.
_Avoid_: Generated repo, instance
